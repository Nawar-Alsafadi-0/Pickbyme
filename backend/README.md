# Backend

This directory will contain the PickByMe backend.

The backend must stay offer-centric rather than product-centric so the platform can support physical products, services, reservations, tickets, stays, and future offer types without redesigning the core.

Planned core domains:
- users
- creators
- providers
- offers
- creator selections
- attribution
- orders / reservations
- commissions
- payments

No framework is locked in by this scaffold yet.
